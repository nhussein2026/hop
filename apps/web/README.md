# Hop Web

This is Hop's React + TypeScript + Vite frontend.

Run it from the repository root:

```bash
yarn workspace web dev
```

The frontend is served at `http://localhost:5173`. During development, Vite proxies `/api` requests to the API at `http://localhost:4321`.

For the complete setup guide, API reference, troubleshooting notes, and product context, see the root [README.md](../../README.md).
